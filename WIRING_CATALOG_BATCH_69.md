## Classifier accuracy caveat (READ FIRST)

This catalog is a **first-pass heuristic**, not authoritative:
- Artifact extraction is regex-based on the description text. Descriptions often mention engine functions (like `can_open`) as context alongside the DEC's actual helper name; the classifier may flag ENGINE_WIRED based on the contextual mention instead of the DEC's own helper.
- Example known false-positive: DEC-091 (drawdown_size_multiplier) is shelf-ready, but the description references `can_open` (engine function) so classifier shows ENGINE_WIRED.
- Therefore the ENGINE_WIRED count of 35 is likely **overstated**; the HELPER_ONLY + CONFIG_CONSTANT_DEAD count of 199 is likely **understated**.
- The wiring-deferred-phrase column (`YES` / `no`) is the most reliable signal: YES means I explicitly wrote 'engine wiring deferred' in the body, which is a self-confessed shelf-ready item.
- **Use this catalog as a first sweep**. Per-DEC manual verification needed before bulk reverts.
