with 5,701 closed trades; engine loop frozen (engine_state ts stuck 04:51) while the heartbeat

   linearly, not a hang locus. backtest.py:915-940.

## Remaining cause (scale-in-pool)
Only variable batch 4 (100 tkr, OK) → batch 5 (200 tkr, hung) is ticker count. Locus is the screen
`imap_unordered` pool at 200-ticker scale: 16 workers each hold a full ohlcv_dict copy + pre-warmed
Quiver bulk caches (1M insider + 500K 13F rows/worker, FIXED cost). At 200 tickers the concurrent
per-worker working set (16× duplication) pushes 128 GB toward OOM → a worker is killed → parent
blocks forever on `imap_unordered` result while the separate heartbeat thread survives — exactly the
frozen-engine + live-heartbeat signature observed. Not a logic bug; a memory-pressure/parallelism bug.
